# 📚 Event-Based Student Registration Form
### Java AWT/Swing · Event Delegation Model

---

## 📌 Overview

This project implements a fully functional **Student Registration System** using **Java Swing** that demonstrates the **Event Delegation Model** — a core Java GUI programming concept where events generated by components are handled by separate, dedicated listener objects.

---

## 🎯 Learning Objectives

| Concept | What is demonstrated |
|---|---|
| `ActionListener` | Button clicks (Submit, Clear, Delete, Export), ComboBox selection |
| `ItemListener` | CheckBox skill toggles, RadioButton gender selection, ComboBox items |
| `FocusListener` | Field highlight on focus-in, validation on focus-out |
| `KeyListener` | Real-time address character counter, numeric-only age input |
| `MouseListener` | Table row click to load data, cursor change on hover |
| `WindowListener` | Confirm-on-close dialog to prevent accidental data loss |

## 🔍 Event Delegation Model — Explained

Java uses the **Event Delegation Model** to decouple event sources from event handlers:

```
  [Event Source]  ──fires──►  [Event Object]  ──dispatched to──►  [Event Listener]
  (JButton, JCheckBox…)       (ActionEvent…)                       (ActionListener…)
```

### How this project wires events

```java
// The FORM itself implements all listener interfaces
public class StudentForm extends JFrame
    implements ActionListener, ItemListener, FocusListener,
               KeyListener, MouseListener, WindowListener { ... }

// Components register the form as their listener
btnSubmit.addActionListener(this);   // ActionListener
chkJava.addItemListener(this);       // ItemListener
tfName.addFocusListener(this);       // FocusListener
tfAge.addKeyListener(this);          // KeyListener
table.addMouseListener(this);        // MouseListener
addWindowListener(this);             // WindowListener
```

## ✨ Features

### 📝 Form Features
- **Personal Info** — Name, Roll Number, Age (numeric-only), Email
- **Gender** — Radio buttons (Male / Female / Other) with `ItemListener`
- **Academic** — Course and Year combo boxes with `ActionListener` + `ItemListener`
- **Skills** — 5 checkboxes with live toggle feedback via `ItemListener`
- **Address** — Text area with real-time character counter (max 200) via `KeyListener`

### 📋 Table Features
- Zebra-striped rows for readability
- Click any row → auto-populate form (edit & re-submit to update) via `MouseListener`
- Live search by name or roll number
- Auto-renumbering after deletion

### 🔒 Validation
- Required field checks (Name, Roll, Age, Email, Course)
- Age must be a number between 10 and 60
- Email must contain `@`
- Red border highlight on invalid fields via `FocusListener`

### 📤 Export
- CSV preview of all registered student records

### 🚪 Safe Exit
- Window close triggers confirmation dialog via `WindowListener`

## 📐 Class Design

```
StudentForm (JFrame)
  │
  ├── implements ActionListener   → actionPerformed(ActionEvent)
  ├── implements ItemListener     → itemStateChanged(ItemEvent)
  ├── implements FocusListener    → focusGained / focusLost (FocusEvent)
  ├── implements KeyListener      → keyReleased(KeyEvent)
  ├── implements MouseListener    → mouseClicked / Entered / Exited (MouseEvent)
  └── implements WindowListener   → windowClosing(WindowEvent)
```

## 📖 Concepts Covered (Academic Reference)

1. **Event Sources** — UI components that generate events
2. **Event Objects** — Carry information about the event (`ActionEvent`, `KeyEvent`, etc.)
3. **Event Listeners** — Interfaces with callback methods (`actionPerformed`, `keyReleased`, etc.)
4. **Registration** — `addXxxListener()` method links source → listener
5. **Delegation** — The JVM dispatches events asynchronously on the EDT (Event Dispatch Thread)
